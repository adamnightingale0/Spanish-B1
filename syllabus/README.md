# Syllabus briefs

One brief per unit, extracted from the book's contents, Léxico and Gramática y comunicación pages.
Each holds only grammar point ids (in the book's order), target words, short function/theme labels,
the writing task type and printed page numbers. No sentences, exercises or texts from the book.
All drills and examples in `content/` are written fresh from these briefs.

Page notes:
- Printed page = PDF page − 1 in the full scan (pageOffset 1).
- `masEjercicios` unit starts are computed: the section starts on p. 178 with seven pages per unit
  (stated in the book's introduction). Check one against the printed book.
- `ejercicios` are the exercise numbers the book cross-references (/MÁS EJ.).
